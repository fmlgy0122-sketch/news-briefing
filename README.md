# 뉴스 브리핑 (개인용 뉴스 낭독)

설정한 시각(기본 06:30 / 17:30, 한국시간)마다 언론사 RSS를 수집해 약 10분 분량의 MP3를 만들고,
팟캐스트 피드와 재생 웹앱으로 배포합니다. 비용은 거의 0원입니다.

## 설치 (최초 1회, 약 10분)
1. GitHub에서 새 저장소를 만들고 이 폴더 전체를 올립니다 (`.github` 폴더 포함).
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. Actions 탭 → build-news-audio → **Run workflow**를 눌러 첫 방송을 만듭니다.
4. 주소: `https://<GitHub아이디>.github.io/<저장소이름>/`

## 안드로이드에서 사용
- **바로 듣기**: 위 주소를 크롬으로 열고 메뉴 → "홈 화면에 추가". 아이콘을 누르면 최신 방송이 자동 재생됩니다.
- **여행/오프라인**: 팟캐스트 앱(Pocket Casts, AntennaPod 등)에 `주소/feed.xml`을 구독하면 와이파이에서 미리 내려받아 로밍·오프라인에서도 재생됩니다.
- **음성 호출**: "헤이 구글, 뉴스 브리핑 열어줘"로 홈 화면 앱을 실행할 수 있습니다. 구글 루틴에 연결하면 한 마디로 실행됩니다.

## 설정 (feeds.json)
| 항목 | 설명 |
|---|---|
| target_chars | 대본 글자 수. 3800자 ≈ 10분 (5분=1900, 15분=5700) |
| voice | 음성. 남성은 `ko-KR-InJoonNeural` |
| rate | 속도. 예: `+10%` |
| sections | 분야와 언론사 RSS 주소 추가/삭제 |
| keep_episodes | 보관할 방송 수 |

### 방송 시각 바꾸기 (휴대폰에서도 가능)
1. 저장소에서 `feeds.json` 파일을 엽니다 → 연필(Edit) 아이콘.
2. 맨 위 `"times": ["06:30", "17:30"],` 의 시각만 바꿉니다 (한국시간, 24시간제, 개수 자유).
   예) 하루 3번: `"times": ["06:00", "12:00", "18:30"],`
3. Commit changes를 누르면 끝입니다. `news.yml` 은 건드리지 않습니다.

동작 방식: 15분마다 "설정 시각이 지났는데 그 시각의 방송이 아직 없는지"만 확인하고, 없을 때만 만듭니다.
GitHub 예약이 늦어져도 다음 확인 때 만회하므로 방송 시각 + 최대 15~30분 안에 생성됩니다.
지금 바로 만들고 싶으면 Actions → build-news-audio → Run workflow.

## 로컬 테스트
```
pip install -r requirements.txt
python build.py --dry-run   # 대본만 확인
python build.py             # MP3까지 생성 (site 폴더)
```

## 주의
- GitHub Pages 주소는 **공개**입니다. 주소를 아는 사람은 들을 수 있으나, 내용은 공개 뉴스 제목·요약뿐입니다.
- 기사 본문 전문은 읽지 않고 제목과 첫 문장 요약만 사용합니다 (저작권 안전).
- 일부 RSS 주소는 언론사 사정으로 바뀔 수 있습니다. 실패한 피드는 자동으로 건너뜁니다. 로그의 `[수집 실패]`를 확인하세요.
- GitHub 예약 실행은 몇 분~수십 분 지연될 수 있습니다. (위 만회 방식으로 보완)
- 공개 저장소는 60일간 커밋 등 활동이 없으면 GitHub가 예약 실행을 자동 중지합니다. 중지 안내 메일이 오면 Actions 탭에서 다시 켜 주세요.
